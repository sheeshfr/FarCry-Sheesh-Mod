## Features

- **True ADS & Better Gunplay:** The majority of weapons now feature true Aim Down Sights (ADS) along with reworked recoil and accuracy.
- **Runs Smooth on Modern PCs:** Uses a pre-configured Vulkan wrapper (`DXVK`) and 4GB memory patch so textures, lighting, and shaders actually work the way they're supposed to on modern graphics cards.
- **New Field Gear & Healing:** Patch yourself up with field bandages, slot in armor plates, and pull out Jack's flip phone on the go (even while driving) to save your progress or check objectives.
- **Pet the Pigs:** Walk up to friendly island boars and give them a proper pet.
- **One-Click Install & Uninstall:** Includes a standalone setup wizard that patches your game in seconds and can restore your install back to 100% untouched vanilla whenever you want.
- **Works on Every Version:** Runs out of the box on **GOG**, **Steam**, **Epic Games**, and **Ubisoft Connect** copies of Far Cry.

## How to Install

1. Download **`FarCry-Sheesh-Mod-v1.0-GitHub.zip`** from [**Releases**](https://github.com/sheeshfr/FarCry-Sheesh-Mod/releases/latest) (contains everything you need).
2. Extract the `.exe` from the zip.
3. Launch it, point it at your Far Cry folder, and click **Install** — done!

To uninstall later, run the `.exe` again anytime to restore your game back to vanilla.
